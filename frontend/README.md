# Frontend

CCTV Safety 프로젝트의 웹 프론트엔드입니다. Vite + React + TypeScript 기반입니다.

## 실행

```bash
cd frontend
npm install
npm run dev       # 개발 서버 (HMR)
```

## 스크립트

| 명령 | 설명 |
| --- | --- |
| `npm run dev` | 개발 서버 실행 |
| `npm run build` | 타입 체크 후 프로덕션 빌드 (`dist/`) |
| `npm run preview` | 빌드 결과 미리보기 |
| `npm run lint` | Oxlint 검사 |
