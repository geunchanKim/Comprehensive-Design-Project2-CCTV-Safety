## 로컬 측정 결과

Windows 11, Python 3.12.10, 임시 SQLite, 저장소 `s4` Unity 탐지 데이터로 조건별 예열 10짝 후 100짝을 측정했다. 실행에는 이번 미커밋 변경이 포함된다.

| 조건 | 평균 처리 ms | p50 ms | p95 ms |
| --- | --- | --- | --- |
| 기준 방법 | 51.243 | 50.021 | 82.969 |
| 배포 기능 조합 cdfg | 92.193 | 75.322 | 208.209 |

최종 표는 테스트 프로세스 종료 후 별도 실행한 결과다. 짝당 입력 탐지는 5~8개, 매칭 결과는 2~4개였다. 기준 방법은 검증·조회, cdfg는 커밋의 평균 비용이 가장 컸고 매칭·위치·ID 연결 구간도 큰 비중을 차지했다. 로컬 반복 실행 간 시간 차이가 있어 실습 서버 PostgreSQL에서 재현 여부를 확인한 뒤 개선할 두 단계를 고른다. 이 표에는 HTTP·네트워크·카메라·대시보드 시간이 없으며, 초당 10짝 또는 전체 지연 1초 달성 판정에는 사용하지 않는다.

## 담당자 회신 반영과 남은 진행

- 근찬 회신: v6 15개 녹화의 실제 서버 재생 로그를 수신·검증했다. 엣지 실행 커밋은 리뷰 공유 기준 `ba17304`다. 전체 2,884건이 HTTP 201이며 응답 누락·실패·버림은 없다. 세션마다 예열 5짝을 제외한 RTT 평균 53.306ms, P90 103.720ms, 큐 대기 P95 35.100ms다. v6 서버는 계측 전 `ba7ec7e`이므로 서버 내부 시간은 아직 없다. 교실 사진 날짜·조끼 준비 현황은 추가 확인한다.
- 성윤 회신: 기존 장면과 sc10을 재사용한다. 지도는 4m 격자에 0.5m 여유를 둔 범위로 반영했다. world 기준 위험구역을 유지하고 구역 정답은 GT에서 계산한다. 디자인 시안과 추가 필드 의견을 기다린다.
- 주말 리뷰: vest·unity-world-xzy 형식은 AI 확인 완료. SSE 제안은 성윤 의견을 포함해 결정한다. 실측 마커 원점 지도 frame ID·범위는 2~3주 차에 합의하고, 서버 최적화 두 단계는 v7 계측 후 결정한다.

세부 결정·실행 명령·sc10 검증 범위는 [회신 반영 문서](specs/week1-integration.md)에 정리했다. v6 캘리브레이션 등록은 완료했으며 계측 배포와 v7 등록은 아직 실행하지 않았다.

실시간 엔드포인트·구역 침입 계산은 2주 차 범위이며 아직 추가하지 않았다. 안전복 결과는 `unknown`, 구역 상태도 판단 전에는 `unknown`으로 전달하도록 준비했다. 전체 위험 판단 플래그는 기존 false를 유지하며 cdfg의 사람–사람 경고 유지 동작은 보존했다.

## 검증과 실행

[측정 절차](specs/server-profiling.md)를 따른다. PR #73 리뷰 반영 후 백엔드 테스트 88개가 통과했다. API 계측·중복 요청, 다각형·지도 범위, 좌표 기준 혼합 거부, 미판단 상태 보존, JSON Schema·예시 일치, 측정 통계·누락 값·세션 혼합 검사, 세션별 예열·표본 합산·dropped 집계, 캘리브레이션 사전 검증과 Unity 메타데이터 시각 검사를 포함한다. 초기 재현 측정 CLI는 조건별 110짝씩 총 220짝을 처리했고, 예열을 제외한 200짝의 속도 표를 생성했다.

```powershell
# 상위 C:\conftest.py의 외부 설정을 제외하고 프로젝트 테스트만 실행
$env:DATABASE_URL = 'sqlite:///./test_cctv.db'
python -m pytest --rootdir=. --confcutdir=backend/tests backend/tests -q -o cache_dir=.pytest_cache
```

이번 변경은 기능 브랜치에서 관리한다. develop·main 병합과 실습 서버 배포는 아직 진행하지 않았다.
