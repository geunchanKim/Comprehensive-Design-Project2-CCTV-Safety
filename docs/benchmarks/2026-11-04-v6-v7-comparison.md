# v6/v7 비교와 서버 개선 우선순위

2026-11-04 BE 재계산. [v6 원본 검증](2026-11-02-edge-v6-replay.md), [v7 원본 검증](2026-11-04-edge-v7-replay.md)을 함께 본다. 두 실행을 합쳐 평균내지 않았다.

## 조건과 해석

두 실행은 각각 같은 15개 녹화를 실제 속도로 재생하고, 세션마다 관측한 첫 5짝을 시간 통계에서 제외했다. 실시간 경로가 최신 짝을 선택하므로 두 실행의 처리 pair와 표본 수가 다르다. 같은 영상 전체에 대한 동일 표본 A/B 검증은 아니다.

v6는 2,884건/예열 제외 2,809표본, v7은 3,020건/2,945표본이다. 양쪽 모두 HTTP 201이며 전송/응답 누락·실패·dropped는 0이다. 두 실행 모두 basic/baseline으로, v7 서버 함수 P95 38.968ms는 cdfg·활성 위험 분석 성능을 대표하지 않는다.

v6 서버는 `ba7ec7e` 계측 전, v7은 실행자 회신 기준 `2e1d2c3`다. 발목 상한은 0.4→0.15m, 매칭 거리 설정은 2.0→1.5m로 달라졌다. 계측·설정·서버 코드·처리 표본이 함께 달라졌으므로 시간 차이를 특정 변경의 개선 효과로 귀속하지 않는다. 계측 전 v6 서버 시간은 unavailable이다.

## 실제 지연 문제

v7의 예열 제외 RTT 1초 초과는 14건이고 예열 포함 전체에서도 14건이다. 해당 표본의 서버 함수 시간은 **11.263~31.477ms**였다. 발생 세션은 s4-t1 2건, s5-t1 1건, s5-t2 1건, s6-t1 1건, s9-t1 5건, s10-t1 3건이다. 서버 계측 범위 밖에서 잔여 지연이 크게 늘어난 것은 확인되지만 TCP 재전송·연결 재수립·서버 요청 대기 중 무엇인지는 이 로그만으로 확정할 수 없다.

동일 pair의 `rtt_ms - total_ms` 2,945표본은 평균 29.620ms/P50 14.894ms/P90 48.628ms/P95 85.888ms/최대 1314.321ms이며 음수는 없다. 순수 네트워크 시간이 아니라 네트워크·요청 파싱·응답 직렬화 등 서버 함수 밖 잔여 시간이다.

같은 행의 `age_ms + queue_ms + rtt_ms`는 평균 263.181ms/P50 186.500ms/P90 415.340ms/P95 857.420ms/최대 2224.000ms다. 1초 초과는 110/2,945건(3.74%)이다. 이는 엣지의 늦게 수신한 입력 프레임 기준 수신→응답까지의 근사 구간 합으로 카메라 노출·디코딩 전 시간이나 브라우저 표시를 포함하지 않는다. 따라서 화면까지 1초 목표를 달성했다고 판정할 수 없고, 관측된 전송 경로에서 이미 1초 초과가 있다. 각 항목의 백분위수를 더하지 않고 pair별 합에서 다시 계산했다.

전체 위험 분석이나 발목 상한을 바꾸어 위 지연을 숨기지 않는다. 2주 차에는 오래된 전송 대기 짝을 버리는 최신성 정책과 버린 수·최대 age 기록을 AI와 검토한다. 유선/현재 연결 조건 반복 측정 및 요청별 연결 재사용·재연결/timeout 기록으로 함수 밖 지연 원인을 분리한다. 큐 축소에 따른 표본 손실과 추적 연속성도 같이 검증한다.

## 서버 개선 후보 두 단계

1. **commit**: 평균 8.294ms(평균 total의 약 41.3%), P95 12.801ms. 15세션별 평균 7.447~8.840ms로 반복 관측됐다. DB flush/트랜잭션 왕복·쓰기 수를 먼저 확인한다. durability를 낮추거나 응답 전에 저장을 생략하지 않고 동일 PostgreSQL 조건에서 검증한다.
2. **validation**: 평균 4.947ms(약 24.6%), P95 13.670ms. 세션별 평균 4.426~5.425ms다. 실제 API의 중복 조회·검증 경로와 쿼리 수를 확인하되 필수 검증·중복 요청 정합성을 유지한다. 요청 파싱 시간 전체가 이 항목에 들어간다고 해석하지 않는다.

두 단계의 평균 비중은 약 66.0%다. 이는 **baseline 서버 함수 내부의 개선 우선순위**이며 현재 1초 꼬리 지연의 원인이 두 단계라는 뜻은 아니다. matching/position/tracking P95 9.447ms도 함께 추적한다. 실측 cdfg 프로파일이 없으므로 cdfg 최적화 순위는 미확정이다. 이번 작업은 측정·후보 선정까지이며 코드 최적화나 배포는 하지 않는다.
