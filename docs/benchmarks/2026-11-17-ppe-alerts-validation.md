# 보호구 미착용 경고 서버 검증

기준: develop `bd7912e`에서 분리한 `feat/server-ppe-alerts`. Windows Python 3.12, SQLite. 기존 `0014` 이후 DB 스키마 변경은 없다.

## 동작과 검증 범위

- 확정 미착용 사람에 대해 `vest`·`helmet` warning을 별도 저장한다. unknown을 미착용으로 바꾸지 않는다.
- 기존 보호구 입력→3회 확정→snapshot·경고 목록, 캐시 유지·만료 후 종료를 API로 대조한다.
- 조끼·안전모 각각 발생·계속·확인 유지·unknown 종료·재발 새 ID·객체 소실·조건 격리·저장 롤백을 검증한다. 동시 미착용은 서로 다른 두 경고로 유지한다.
- 최종 backend 전체 SQLite 130개·AI 53개 통과. 백엔드 실행은 외부 pytest 설정을 읽지 않도록 `--confcutdir=. --rootdir=.`를 사용했다.
- JSON Schema를 실제 모델에서 갱신하고 기존 예시·계약 테스트로 대조한다.
- 로컬 프론트 빌드·린트 통과. Node 설치 경로를 명시했고 외부 `C:\postcss.config.js`를 상속해 발생한 Tailwind 누락 오류는 임시 빈 PostCSS 설정으로 격리해 확인했다. 임시 설정은 제거했으며 제품 설정은 바꾸지 않았다. 원격 PR에서도 frontend-test를 확인한다.

전체 위험 분석 false는 유지한다. 미착용 수준은 기존 화면 예시의 warning과 일치한다. 사람별 안전모 상태 화면·경고음·관리자 알림·실제 모델 전송·카메라→화면 검증은 이번 자동 검사로 완료 처리하지 않는다. 새로운 종류 `helmet`의 표시 타입·제목만 기존 화면에 호환되게 추가한다.
