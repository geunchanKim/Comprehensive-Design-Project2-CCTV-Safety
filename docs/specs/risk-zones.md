# 바닥 위험구역 형식 초안

Unity 제작과 대시보드 표시가 같은 구역을 사용하도록 꼭짓점과 주의 거리를 공유한다. 1주 차에는 형식과 검토용 예시를 준비하고, 침입 판정과 실시간 전달은 2주 차에 구현한다.

## 정의

`backend.dashboard.ZoneSet`이 JSON을 검증한다. `schema_version=1.0`, `coordinate_system=world_xy_m`, `zones` 배열을 사용한다.

| 구역 필드 | 조건 |
| --- | --- |
| `zone_id` | 1~64자, 같은 정의 안에서 유일 |
| `name` | 1~128자, 화면 표시 이름 |
| `vertices` | 바닥 `[X,Y]` m 좌표 3~64개. 경계를 따라 시계 또는 반시계 순서 |
| `warning_distance_m` | 구역 바깥 주의 거리, 0 이상 유한수 |
| `enabled` | 기본 true. false인 구역은 판단에서 제외 |

마지막 꼭짓점에서 첫 꼭짓점은 자동 연결하므로 첫 점을 반복하지 않는다. 중복점, 면적 0, 자기 교차·접촉, 연속 변의 일직선 중복, NaN·무한대는 거부한다. 오목 다각형도 허용한다. 구멍이 있는 구역은 지원하지 않는다. 구역끼리 겹치면 각 구역을 독립적으로 판단한다.

## 판단 기준

사람의 추정 월드 좌표 중 `[X,Y]`를 사용한다. 높이 값은 구역 판단에서 제외한다.

- 내부 또는 경계 위: `intrusion`, `distance_m=0`.
- 외부이며 경계까지 최단 유클리드 거리가 주의 거리 이하: `warning`.
- 그 밖: `outside`.
- 위치 또는 판단 결과가 없음: `unknown`, 거리 null. 사라진 객체의 이전 침입을 새 결과처럼 반복하지 않는다.

이 기준은 2주 차 구현의 입력 계약이며 현재 침입 판단이 실행되는 것은 아니다.

## 교실 예시

[classroom-risk-zones.example.json](examples/classroom-risk-zones.example.json)은 5m×5m 지도에서 X=3~4m, Y=3~4m인 1m×1m 사각형과 주의 거리 0.5m를 정의한다. Unity 형식으로는 높이 y=0, x=3~4m, z=3~4m이다.

예시 기대 상태: 서버 바닥 좌표 `(3.5,3.5)`는 침입, `(2.75,3.5)`는 주의, `(2,3.5)`는 외부다. 실제 교실 원점·축과 장애물 위치가 확인되면 좌표를 교체한다. 이 파일은 운영 구역으로 자동 등록되지 않는다.
