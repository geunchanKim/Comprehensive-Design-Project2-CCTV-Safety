# 11/25 의자 가림 후속 검증

## 문제와 구현 범위

[촬영 결과](../shoot-results-1125.md)의 s27 의자 검출 비율은 29%였고 가림 중 경고가 끊겼다. s25 t3와 s26에서도 끊김이 보고됐다. 검출·짝짓기·네트워크 원인을 구분해야 하며 유지 시간 연장만으로 해결됐다고 판단하지 않는다.

서버의 고정 3초 유지 시간을 `CHAIR_HOLD_MS`로 조정할 수 있게 했다. 기본값 3000ms는 유지하고, 0은 비활성화, 허용 범위는 정수 0~10000ms다. health와 탐지 응답의 `chair_hold_ms`로 실제 적용값을 확인한다. 운영 위험 분석 기본값과 거리·높이 기준은 변경하지 않는다.

## 재생 절차

1. 별도 데모 서버에서 같은 코드·캘리브레이션·`basic/f-cd` 조건을 사용한다. 실제 운영 DB에서 실험하지 않는다.
2. 3000ms를 기준으로 먼저 재생하고 5000ms와 비교한다. 설정 변경 후 서버를 재시작하고 health를 저장한다. 5000ms는 실험 후보이며 권장 운영값이 아니다.
3. 각 실행에 새 세션을 등록하고 해당 세션의 지도·캘리브레이션도 준비한다. 같은 세션에 송신자를 중복 실행하지 않는다.
4. s25 t3, s26 t1, s27 t1을 원래 속도로 재생한다. 이동·퇴장 부작용은 s28과 s29 t2도 함께 확인한다. 네트워크 stale/실패가 있으면 유지 시간 효과와 분리한다.
5. 탐지 응답과 snapshot을 기록한다. held 위치는 Detection 및 위치 CSV에 저장되지 않으므로 CSV만으로 효과를 계산하지 않는다.
6. 경고 수명은 서버 시계 기준이므로 빠른 재계산 결과를 경고 연속성 실측으로 쓰지 않는다.

## 비교 항목

| 항목 | 3000ms | 5000ms |
| --- | --- | --- |
| 전송 실패·stale 비율 | 미측정 | 미측정 |
| 실제 관측 / held 의자 비율 | 미측정 | 미측정 |
| 사람–의자 경고 ID·끊김 시간 | 미측정 | 미측정 |
| 중복 의자·이동 후 옛 위치 잔류 | 미측정 | 미측정 |
| 퇴장 후 불필요한 경고 지속 | 미측정 | 미측정 |
| 입력 중단 후 활성 경고 종료 | 미측정 | 미측정 |

채택 전에는 가림 구간 경고가 이어지는지와 이동·퇴장 시 잔상 경고가 늘지 않는지를 모두 확인한다. 실측 근거 없이 기본값이나 데모 환경을 연장하지 않는다.

## 별도 확인이 남은 항목

- 실제 화면의 확인 버튼 클릭: 세션·alert_id·클릭 시각·HTTP 204와 저장된 acknowledged_at_ms/action 대조. 기존 경고에 대신 확인 요청을 보내지 않는다.
- 입력 중단 시 stale 표시와 활성 경고 종료의 화면·서버 대조.
- 위험구역 꼭짓점과 좌표계가 합의된 세션에서 접근·진입 실험. 빈 zones 지도로 침입 성공을 주장하지 않는다.
- 원본 촬영 로그·영상은 팀 드라이브 자료가 필요하다. 이 저장소의 촬영 요약만으로 재생 결과나 정답 기반 정확도를 확정할 수 없다.
- SW 등록 보완 완료는 실제 회신·접수 근거가 필요하며 코드 PR 병합과 구분한다.
