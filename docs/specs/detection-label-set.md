# 실제 영상 탐지 오탐률 라벨 세트 (사람·의자)

작성일: 2026-11-17. 담당: 근찬. 스크립트: `ai/eval/label_set.py`

## 왜 필요한가

객체 탐지 오탐률(사람·의자가 아닌 것을 탐지하거나, 잘못된 상자를 그린 비율)은 지금까지 Unity 시뮬레이션에서만 쟀다. 실제 강의실 녹화에는 사람·의자 **상자 정답**이 없기 때문이다. 정지 프레임 정답(`ai/eval/packs/real-*`)은 바닥 위치(점)뿐이라 상자가 맞는지는 판정할 수 없다.

그래서 녹화에서 프레임을 골라 사람이 상자를 직접 확인하고, 그 정답으로 탐지기를 채점한다. 목표는 사람 100명, 의자 100개 이상이다.

## 만든 라벨 세트 (`classroom-det-v1`)

| 항목 | 값 |
| --- | --- |
| 위치 | `~/datasets/classroom-det-v1` (git에 올리지 않음. 팀원 얼굴이 있어 공유는 팀 드라이브로만) |
| 이미지 | 90장 (강의실 녹화 15개 전부, cam1·cam2 번갈아) |
| 초안 상자 | 사람 215개, 의자 120개 (COCO yolo11n, conf 0.25) |
| 고르는 방법 | 녹화마다 30짝 간격으로 후보를 만들고 고정 seed로 섞어 차례로 넣음. 모델 결과로 고르지 않음 |

```bash
cd ai
python eval/label_set.py make --out ~/datasets/classroom-det-v1      # 이미 만듦. 다시 만들면 고친 라벨을 덮어쓰지 않게 멈춤
```

폴더 구성: `images/`(프레임), `labels/`(**고칠 파일**), `labels_pre/`(초안 원본, 고치지 않음), `classes.txt`(0 person, 1 chair), `manifest.csv`(파일별 녹화·프레임·카메라).

## 라벨링 방법

초안은 모델 결과라서 그대로 정답으로 쓰면 오탐률이 0처럼 나온다. **모든 이미지를 한 장씩 보고** 아래처럼 고친다.

1. 틀린 상자 지우기: 사람·의자가 아닌 곳의 상자, 같은 물체에 겹친 두 번째 상자 (예: 의자 전체 상자 + 등받이만 감싼 상자 → 등받이 상자 삭제)
2. 놓친 상자 그리기: 초안에 없는 사람·의자
3. 클래스 고치기: 의자를 사람으로(또는 반대로) 붙인 상자
4. 크게 어긋난 상자 맞추기: 물체의 절반 정도만 감싸는 상자. 몇 픽셀 차이는 고치지 않아도 된다 (IoU 0.5 이상이면 맞음으로 채점)

라벨 규칙

| 대상 | 규칙 |
| --- | --- |
| 사람 | 보이는 사람 전부. 가려지거나 화면 끝에서 잘려도 **보이는 부분 전체**를 감싼다 |
| 의자 | 의자 하나에 상자 하나. 등받이·좌판·다리·바퀴까지 보이는 부분 전체 |
| 라벨 안 함 | 책상, 캐리어, 가방, 유리·바닥에 비친 모습, 포스터·화면 속 사람 |
| 작은 것 | 높이 약 20px(원본 1920×1080 기준) 미만은 그려도 되고 안 그려도 된다. 채점에서 빠진다 |
| 애매한 것 | 반 이상 가려져 무엇인지 알기 어려운 것은 그리지 않고, 파일 이름을 메모해 둔다 |

## 도구

YOLO 형식(이미지 + 같은 이름의 `.txt`)을 읽고 쓰는 도구면 된다.

- **makesense.ai** (설치 없음, 브라우저): 이미지 폴더를 열고 라벨 이름을 `person`, `chair` 순서로 만든 뒤, YOLO 형식으로 `labels/`의 txt를 가져온다. 다 고치면 YOLO 형식으로 내보내 `labels/`에 덮어쓴다. 파일은 브라우저 안에서 처리되지만 외부 사이트이므로, 걱정되면 아래 로컬 도구를 쓴다.
- **Label Studio** (로컬 설치): `pip install label-studio` 후 YOLO 가져오기로 같은 폴더를 연다.

클래스 순서가 `0 person`, `1 chair`로 유지되는지 내보낸 뒤 txt 한두 개를 열어 확인한다.

## 채점

```bash
cd ai
python eval/label_set.py score ~/datasets/classroom-det-v1 --vis
```

- 탐지기: 엣지와 같은 COCO yolo11n, 입력 1280, 사람 conf 0.5·의자 0.4. 고른 프레임은 연속이 아니라서 추적 없이 탐지한다 (엣지가 추적 번호 없는 상자를 버리는 효과는 빠진다)
- 맞춤: 같은 클래스끼리 IoU 큰 순서로 1:1, IoU 0.5 이상이면 맞음
- **오탐률** = 정답과 안 맞는 탐지 / 전체 탐지, **검출률** = 맞은 정답 / 전체 정답
- `fp_from_other_class`: 오탐 중 다른 클래스 정답 위에 그린 것 (예: 의자를 사람으로)
- 결과: `score.json`(요약), `score_boxes.csv`(상자별), `vis/`(틀린 프레임. 빨강 오탐, 파랑 놓침, 초록 맞음)
- `labels/`가 초안과 전부 같으면 경고를 띄운다 (라벨링 전 채점)
