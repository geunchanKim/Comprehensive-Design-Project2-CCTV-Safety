## 왜 찍나

지금 실제 영상은 10/14 논문용 강의실 녹화뿐이다. 이 녹화로는 아래 세 가지를 확인할 수 없다.

| 확인할 것 | 10/14 녹화로 안 되는 이유 | 이번 촬영에서 할 것 |
| --- | --- | --- |
| 보호구 판별 정확도 | 안전모·조끼 착용자가 없다 | 착용 조합을 바꿔 가며 찍고, 헷갈리기 쉬운 야구모자도 넣는다 |
| 근접 경고 오탐·미탐 | 정답 거리가 1m 격자뿐이라 경고 기준(0.5m·1.0m) 양쪽 거리가 없다 | 기준 양쪽 거리(0.4·0.6·0.9·1.1m)에 표시를 추가한다 |
| 짝 끊김 원인 | 사람이 snapshot에서 자주 빠지는데 원인 구분용 장면이 없다 | 겹치기 장면을 넣는다 (걷기·가장자리는 10/14에 찍었다) |

찍은 프레임은 사람·의자 라벨 세트 v2(초안 없이 직접 라벨링)에도 쓴다.

## 카메라 배치

이번 촬영은 10/14 실험을 이어 가는 것이 아니라 **새로 찍는 데이터**다. 그래서 카메라 자리는 10/14과 맞추지 않고, 이번에 확인할 것(보호구·근접·짝 끊김)에 맞게 새로 정한다. 캘리브레이션도 새 자리 기준으로 새로 한다(아래 "캘리브레이션 방식").

11/20 분석에서 사람이 빠지는 원인의 약 50%, 의자가 빠지는 원인의 81%가 **한 카메라에서만 보이는 것**이었다. 그래서 두 카메라가 함께 보는 구역을 최대한 넓힌다.

| 기준 | 내용 | 이유 |
| --- | --- | --- |
| 두 카메라 모두 격자 전체를 본다 | 격자 x 0~3, y 0~3 (3m × 3m)의 십자 16개와 ArUco 마커 8개가 두 화면에 다 들어오게 | 한 카메라에서만 보이는 구역을 없앤다. 캘리브레이션은 두 카메라가 모든 마커를 봐야 한다 |
| 격자의 이웃한 두 모서리 쪽에 둔다 | 예: cam1은 원점 쪽 모서리 바깥, cam2는 (3, 0) 쪽 모서리 바깥(현장 자리: cam1 (−0.5, −2.5), cam2 (3.5, −2.5)). 둘 다 격자 가운데 (1.5, 1.5)을 향한다. 두 카메라가 보는 방향 사이 각도가 60~90°가 되게. 현장은 공간이 좁아 약 53°다 | 한 카메라에서 사람이 의자나 다른 사람을 가려도, 다른 카메라는 옆에서 봐서 보인다. 두 카메라를 나란히 두면 같은 방향에서 가려진다 |
| 높이 2.5~3m, 아래로 30~45° | 격자 가장자리에서 2~3m 떨어진 곳 | 너무 위에서 내려다보면 사람 검출이 약해진다(천장크레인 PoC 경험). 조끼는 옆에서, 안전모는 위에서 잘 보이니 중간 각도로 |
| 머리부터 발까지 들어온다 | 가장 가까운 격자 점과 가장 먼 격자 점에 사람이 서서, 두 화면에서 머리와 발이 다 보이는지 본다 | 발 위치(발목)와 안전모를 둘 다 봐야 한다 |
| 한 번 정하면 움직이지 않는다 | 줌·초점 고정, 거치대 다리 자리를 바닥에 테이프로 표시, 케이블은 바닥에 붙여 걸리지 않게 | 캘리브레이션 뒤 카메라가 움직이면 위치가 전부 틀어진다 |

- 카메라 자리와 높이를 줄자로 재서 기록지 맨 위에 적고, 두 카메라 화면을 캡처해 둔다.
- 창문을 정면으로 보는 방향(역광)은 피한다.

## 바닥 테이프

**바닥에 테이프를 붙인다.** 정지 장면의 정답 위치를 테이프 기준으로 적기 때문에, 테이프가 정확해야 오탐률·미탐률이 맞게 나온다.

### 1. 1m 격자

- 1m 간격 **십자(+) 표시**를 x 0~3, y 0~3 범위에 붙인다. 4 × 4 = 16개.
- 십자 한 변은 20cm 정도로 하고, 교차점이 정확한 위치다.
- 격자 십자는 **바닥과 잘 구분되는 한 가지 색**으로 붙인다. 십자는 정답 위치와 ArUco 마커를 놓을 자리로만 쓴다(캘리브레이션 계산은 마커로 한다, 아래 4번).
- 원점 (0, 0)은 격자 한쪽 모서리 십자로 정하고, +x·+y 방향으로 화살표 테이프를 하나씩 붙인다. 원점에는 ArUco ID 0을 놓으므로, **마커의 x·y 방향이 화살표와 같아야** 한다. 원점과 축 방향은 사진으로 남긴다.
- 10/14 테이프는 남아 있지 않으므로 새로 붙인다. 원점과 축 방향도 이번 카메라 배치에 맞게 새로 정한다.

### 2. 가까운 거리 표시 (이번에 추가)

근접 경고 기준은 **주의 1.0m 미만, 위험 0.5m 미만**이다. 기준선에 딱 맞춰 서면 위치 오차(사람마다 수 cm) 때문에 경고가 나올지 말지가 반반이라 채점할 수 없다. 그래서 **기준선에서 10cm씩 떨어진 거리**에 표시해서, 경고가 반드시 나와야 하는 거리와 나오면 안 되는 거리로 나눈다.

격자 십자와 **다른 색 테이프**로 작은 막대(−)만 붙인다. 격자 점과 헷갈리지 않게 하기 위해서다. 기준점은 두 개다.

- **P = (1, 1)**: 가로 줄 (y = 1)
- **Q = (3, 0)**: 세로 줄 (x = 3)

| 거리 | 정답 판정 | 가로 줄 표시 (P 기준) | 세로 줄 표시 (Q 기준) |
| --- | --- | --- | --- |
| 0.4m | 위험 | (1.4, 1) | (3, 0.4) |
| 0.6m | 주의 | (1.6, 1) | (3, 0.6) |
| 0.9m | 주의 | (1.9, 1) | (3, 0.9) |
| 1.1m | 경고 없음 | (2.1, 1) | (3, 1.1) |
| 1.5m | 경고 없음 | (2.5, 1) | — |
| 2.0m | 경고 없음 | 격자 점 (3, 1) | — |

- 줄을 두 방향으로 둔 이유: 카메라에서 보는 방향에 따라 위치 오차가 달라서다.
- 0.5m·1.0m 정확한 거리에는 서지 않는다. 격자 점 (2, 1)은 1.0m 거리지만 근접 장면에서는 정지 위치로 쓰지 않는다.
- 표시는 줄자를 기준점 교차점에 대고 잰다. 붙인 뒤 다른 사람이 한 번 더 잰다.
- 이 표시는 캘리브레이션 계산에 쓰지 않으므로, 계산 뒤 화면 위에 되돌려 그려 보는 **추가 확인용 점**으로도 쓴다.

### 3. 의자 자리와 방향

- 의자는 두 자리에 둔다: **Q (3, 0)** (s25·s26), 격자 점 **(3, 2)** (s27). 자리는 "장면"의 그림 참고.
- 의자는 **네 다리 가운데가 표시 위에 오게** 놓는다. 정답 위치 = 네 다리 가운데.
- 의자 방향은 두 가지로 정한다. 다리 네 곳에 ㄱ자 표시를 하고 옆에 방향 번호를 적는다.
  - **방향 1**: 앉는 쪽이 +y를 본다 (등받이가 −y 쪽)
  - **방향 2**: 앉는 쪽이 +x를 본다 (방향 1에서 시계 반대로 90° 돌림)
- 지금 엣지는 의자 위치로 상자 아래 가운데를 쓴다. 이 점은 의자 방향과 카메라 각도에 따라 다리 가운데에서 다르게 벗어날 수 있어서, 원래 방향 두 가지로 차이를 재려 했다. 이번 8개 장면은 방향 1로 찍고, 방향 2는 s26에서 다리가 안 가려질 때와 시간이 남을 때만 쓴다.
- 11/20 분석(`docs/specs/ppe-integration-replay.md` 8번)에서 사람-의자 경고가 끊기는 주된 원인은 위치 흔들림이 아니었다. **사람이 의자를 가려서 의자가 결과에서 빠지는 것**이었다 (경고 끊김의 약 80%, 의자를 놓친 사진의 67%는 사람이 의자를 절반 넘게 가림). 그래서 s27에 **의자를 가리는 자리**를 넣었다.

### 4. 캘리브레이션 방식 (ArUco 마커, 저장소 도구 그대로)

카메라를 새 자리에 두므로 캘리브레이션을 새로 한다. 바닥에 ArUco 마커 8개를 깔고 저장소의 도구(`ai/calibration/build_calibration.py`, 안에서 `calibrate_grid.py` 사용)로 계산한다. 사용법은 `ai/calibration/README.md` 4·5번과 [calibration-day-checklist.md](calibration-day-checklist.md).

| 무엇 | 방법 |
| --- | --- |
| 내부 파라미터 (초점거리·왜곡) | 기존 ChArUco 결과 `ai/calibration/results/cam1_intrinsics.json`, `cam2_intrinsics.json`을 그대로 쓴다. 해상도(1920×1080)가 다르면 도구가 멈춘다. 카메라나 줌을 바꿨을 때만 다시 찍는다 |
| precise 프로필 | 마커 ID 0~5의 **중심 6개**로 카메라 위치를 계산(다점 PnP)하고, 계산에 안 쓴 ID 6·7로 cm 오차를 잰다. 마커 크기와 상관없이 중심만 쓴다 |
| basic 프로필 | ID 0 마커 하나의 자세로 계산한다. **ID 0의 실제 인쇄 크기**가 `ai/calibration/config.py`의 `ARUCO_MARKER_LENGTH_M`(0.176m)과 같아야 한다 |

마커 자리 (기본안, 마커 **중심**을 격자 십자 교차점에 맞춘다):

| 마커 | 역할 | 자리 (x, y, z) |
| --- | --- | --- |
| ID 0 (A4, 18cm) | 계산 + 원점 | (0, 0, 0) |
| ID 1 (A3, 27cm) | 계산 | (3, 0, 0) |
| ID 2 | 계산 | (0, 2, 0) |
| ID 3 | 계산 | (3, 2, 0) |
| ID 4 | 계산 | (1, 1, 0) |
| ID 5 | 계산 | (2, 1, 0) |
| ID 6 | 검증 (바닥, 먼 곳) | (3, 3, 0) |
| ID 7 | 검증 (높이 다름, 먼 곳) | (0, 3, 상자 높이) — 상자 위에 올리고 높이를 줄자로 잰다 |

- 도구는 아래 조건을 못 맞추면 멈춘다: 계산점 6개 이상·한 줄 아님, 계산점이 화면 가로·세로 25% 이상에 퍼짐, 검증점 2개 이상, 검증점 중 하나는 높이가 다르고 하나는 모든 계산점보다 카메라에서 멀다. 카메라 자리에 따라 "멀다" 조건이 안 맞으면 ID 6·7을 격자 먼 쪽 모서리로 옮긴다.
- 좌표 파일 `ai/calibration/grid_points.json`은 `grid_points.template.json`을 복사해 위 표대로 미리 채워 둔다. ID 7 높이만 당일 잰 값으로 고친다.
- 10/14에 마커 계산이 틀렸던 이유는 ID 1 하나로 계산하면서 크기를 0.27m로 넣었기 때문이다(실제 0.176m, 거리 1.53배). 이번에는 precise가 중심만 쓰고, basic은 10/14에 실측한 ID 0 출력물(0.176m)을 그대로 쓰므로 같은 실수를 막는다.
- 마커는 캘리브레이션 녹화(`s0/calib`) 때만 깔고, 장면 촬영 전에 걷는다(사람 발에 밀리고, 탐지에 섞이지 않게). 끝날 때 `s0/calib-end`를 찍을 때 같은 자리(십자)에 다시 깐다.
- 확인 기준: report의 precise 검증점(ID 6·7) 오차가 **5cm 이내**. 넘으면 마커 자리와 `grid_points.json` 좌표를 확인하고 다시 찍는다.

### 그림 (위에서 본 모습, 1칸 = 1m)

```text
  y
  3      +     +     +     +
  2      +     +     +     +
                           ·             (3, 1.1)
  1      +     P ·· ·+· ·  +             P = (1,1),  · = x 1.4 · 1.6 · 1.9 · 2.1 · 2.5
```

### 테이프 붙인 뒤 확인

- 격자 바깥 네 변이 모두 **3.00m**인지 잰다.
- 바깥 정사각형의 두 대각선을 잰다. 둘 다 **4.24m**여야 한다.
  - (0, 0) → (3, 3)와 (3, 0) → (0, 3)
- 변이나 대각선 하나라도 2cm 넘게 차이 나면 그 줄을 다시 붙인다.
- 두 카메라 화면에 격자 전체가 보이는지 확인한다. 한 카메라에서라도 안 보이는 점은 정지 위치로 쓰지 않고, 기록지 "메모"에 적는다.

## 강의실 정리

- 화면 안의 **다른 의자·가방·캐리어는 모두 화면 밖으로 치운다.** 10/14에는 캐리어를 의자로 잘못 본 오탐이 있었고, 화면에 남은 의자는 사람-의자 근접 경고를 만든다.
- 고정된 책상·의자처럼 치울 수 없는 것은 사진을 찍고 대략 위치를 재서 기록지 맨 위 "고정 물체" 칸에 적는다(나중에 라벨에 넣는다).
- 조명은 켤 수 있는 것을 모두 켜고, 촬영 동안 바꾸지 않는다. 블라인드 상태도 처음 상태로 둔다.

## 인원과 역할

촬영 인원은 3명이다. 2명이 출연하고 1명이 기록을 맡는다.

| 역할 | 사람 | 하는 일 |
| --- | --- | --- |
| A·B | 출연 2명 | 장면에 들어가는 사람. 촬영 내내 **같은 옷**을 입고, 옷 색을 기록지에 적는다 |
| 기록 담당 | 1명, 노트북 옆 | 녹화 켜기·끄기, 기록지 쓰기, "이동"·"정지" 말하기. 장면 사이 의자 옮기기·보호구 건네기는 출연자와 같이 한다 |

- 녹화 시각은 노트북 시계로 저장된다. 기록지 시각도 **노트북 화면 시계**를 보고 적는다. 그래야 기록지 시각으로 녹화 프레임을 바로 찾을 수 있다.
- 녹화에는 소리가 남지 않는다. "이동"·"정지"는 출연자에게 알리는 신호일 뿐이고, 정지 구간은 기록지 시각과 사진을 보고 고른다.

### 깜빡임 동기화 (1:00 ~ 1:05)

두 카메라는 사진이 노트북에 도착하는 시각에 차이가 있다(`--cam2-offset-ms`). 이걸 나중에 재려고 따로 녹화한다.

1. `--out runs/real/classroom-1125/s0 --name sync`로 녹화를 켠다.
2. 한 사람이 **두 카메라에 모두 보이는 자리**(격자 가운데 근처)에서 휴대폰 손전등을 카메라 쪽으로 향하고, 2초 간격으로 5번 켰다 끈다.
3. 녹화를 끈다.

촬영 때는 `--cam2-offset-ms`를 주지 않고(0) 녹화하고, 잰 값은 재생할 때 넣는다.

## 장면

정지 장면은 **각 위치에서 5초 동안 가만히 서 있기**. 이 구간이 정답 프레임이 된다. 기록 담당이 "정지"라고 말한 뒤 5초를 세고 "이동"이라고 말한다. 출연자는 **두 발 사이에 표시가 오게** 서고, 정답 위치는 두 발 사이 가운데다(엣지의 발 위치도 두 발목의 가운데다).

보호구 조합 기호: **H** = 안전모 씀, **V** = 조끼 입음, **–** = 안 씀. 추가로 **(모자)** = 야구모자 씀(안전모 아님).

- 장면 번호는 **s20부터** 쓴다. 예전 계획의 s1~s13과 겹치지 않게 하기 위해서다. 추가 장면은 s28부터 매긴다.
- **녹화 하나에 의자 자리 하나, 확인할 것 하나**로 나눴다. s20~s22를 빼면 움직이는 사람은 한 명이다. 의자를 옮기거나 사람·옷을 바꿀 때는 녹화를 끈다.
- 의자는 한 개만 쓰고, 안 쓰는 장면에서는 화면 밖으로 치운다.
- 10/14 촬영에서 이미 본 마주 걷기, 엇갈려 지나가기, 물체 밀기, 가장자리 돌기는 다시 찍지 않는다.
- 거리는 사람은 두 발 가운데, 의자는 네 다리 가운데 기준이다. 0.5m·1.0m에 딱 맞는 정지는 없다.
- 정지 위치는 모두 바닥에 붙인 격자 십자나 가까운 거리 표시다. s27의 가리는 자리 두 곳만 리허설 때 막대를 새로 붙인다.
- 걷는 동안은 위치·경고를 채점하지 않고, 정지 구간만 본다.

```text

  3      +     +     +     +
  2      +     +     +     R
  1      +     P     +     +
  0      O     +     +     Q
         0     1     2     3   x
  Q = (3, 0): s25·s26 의자    R = (3, 2): s27 의자    P = (1, 1): s24에서 A가 서는 자리
```

#### s20~s22. 보호구 정지

A·B가 서 있기만 하고, 안전모·조끼 판별만 본다.

- **동선:** 두 사람이 나란히 뒤로 물러나며 자리마다 5초. 늘 3m 떨어져 있고 엇갈리지 않는다. 근접 경고는 없다.

| 순서 | A | B | 메모 |
| --- | --- | --- | --- |
| 1 | (0, 0) | (3, 0) | 가까운 줄 |
| 2 | (0, 1) | (3, 1) | 한 칸 뒤 |
| 3 | (0, 3) | (3, 3) | 먼 줄 |

- 세 장면의 위치는 같고 착용만 바꾼다(위 표). 몸은 두 카메라 사이를 보게 선다.
- 먼 줄에서 머리가 화면 밖으로 잘리면 3번을 (0, 2)·(3, 2)로 바꾸고, 세 장면 모두 같은 자리를 쓴다.

#### s23. 겹치기

cam1에서 사람이 다른 사람에게 가려질 때 두 카메라의 짝이 끊기는지 본다.

- **배치:** A는 (1, 0)에 계속 서 있다. 두 사람은 늘 2m 이상 떨어져 있다.
- **동선:**
  1. B가 (2, 2)에 서서 5초(cam1에서 겹침).
  2. B가 (1, 2)로 옮겨 5초(안 겹침).
  3. B가 (2, 2)로 돌아와 5초. 2~3을 모두 3번 한다.
- 리허설 때 cam1 화면에서 실제로 겹치는지 본다. 안 겹치면 자리를 옮기고 기록지 "바꾼 정지 위치"에 적는다.
- **기대 경고:** 없음.
- **채점:** 겹친 동안 B를 놓친 비율, 다시 나타난 뒤 ID 유지, 두 카메라 짝이 끊긴 프레임 비율.

#### s24. 사람에게 다가가기

- **배치:** A가 P (1, 1)에 계속 서 있다.
- **동선:** B가 (3, 1)에서 y = 1 줄을 따라 A 쪽으로 걸으며 표시마다 5초씩 선다. 마지막 정지 뒤 멈추지 않고 (3, 1)로 돌아가 5초 선다.

- 0.4m에서는 서로 마주 보고 선다.

#### s26. 의자 뒤 사람에게 다가가기

다리가 의자에 가려진 사람에게 경고가 맞는 쌍으로 붙는지, 두 쌍의 경고가 동시에 맞게 나는지 본다.

- **배치:** 의자를 Q (3, 0)에 방향 1로 둔다. B는 의자 바로 뒤 (3, 0.4)에 계속 선다.
- **가림 조건:** 리허설 때 적어도 한 카메라에서 B의 다리가 의자에 가려지는지 본다. 안 가려지면 의자를 방향 2로 돌리고 기록지에 적는다.

| 정지 | A | B | A–B | A–의자 | B–의자 | 기대 경고 |

- A–의자는 끝까지 1.1m 이상이라, 여기서 경고가 나오면 오경보다.
- **채점:** 쌍별 경고, 가려진 동안 B의 위치 오차.

#### s27. 의자 가리기

- **배치:** 의자를 격자 점 (3, 2)에 방향 1로 둔다. Q에서는 cam2 쪽에 선 사람의 발이나 머리가 화면에서 잘린다. A는 화면 밖에 있다.
- **동선:** B가 의자에서 0.6m 떨어져 cam1과 의자 사이에 5초, cam2와 의자 사이에 5초 선다.

| 정지 | B 위치 (후보) | B–의자 | 기대 경고 |
| --- | --- | --- | --- |
| 1 | cam1 쪽 (2.63, 1.53) | 0.6m | 주의 |
| 2 | cam2 쪽 (3.07, 1.4) | 0.6m | 주의 |

- 리허설 때 사람이 의자를 절반 넘게 가리는지 보고, 줄자로 의자 중심(다리 가운데)까지 0.6m를 맞춘 뒤 막대를 붙인다. 실제 좌표를 재서 기록지에 적는다.
- **채점:** 주의 경고가 끊기지 않고 이어지는지, 의자가 결과에서 빠지는지.

시간이 남으면 위에서부터 추가한다(보호구 조합은 의자 방향 다음).

## 기록지 양식

장면마다 한 줄씩 적는다. 정답 라벨을 만드는 근거라서 빠뜨리지 않는다. 시각은 **노트북 화면 시계** 기준.

맨 위에 한 번만 적는 것:

| 항목 | 적을 것 |
| --- | --- |
| 출연자 옷 | A: (예) 검은 티·청바지, B: … |
| 카메라 | cam1·cam2 IP, 설치 위치, 바닥에서 높이 |
| 격자 | 원점 십자 위치, +x·+y 방향 (사진 번호) |
| 고정 물체 | 치우지 못한 책상·의자 위치 |
| 바꾼 정지 위치 | 리허설에서 옮긴 자리 |

장면별:

| 장면 | 시도 | 시작 시각 | 끝 시각 | A 착용 | B 착용 | 위치 순서 | 결과 | 메모 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| s20 | t1 | 14:05:10 | 14:05:40 | H+V | – (모자) | 위치표 1~3 | 사용 | B가 3번 자리에서 늦게 정지 |
| s27 | t1 | 14:31:00 | 14:31:30 | 화면 밖 | – | 의자 (3, 2), cam1 쪽 (2.63, 1.53)·cam2 쪽 (3.07, 1.4) | 사용 | |

- 결과는 "사용" 또는 "버림". 버린 시도도 줄을 남긴다.

## 정해야 할 것 (피드백 부탁)

1. **보호구 준비**: 멘토님께 빌릴 수 있는지 답을 기다리는 중이다. 못 빌리면 사야 한다(안전모 1개·조끼 1벌). 누가 언제까지?
2. **근접 장면에도 보호구를 쓸지**: 근접 판정은 발 위치로 하니 보호구 영향이 거의 없다. **쓰는 쪽을 제안한다**(보호구 평가 데이터가 늘어남). 반대가 없으면 "한눈에 보기" 표대로 찍는다.
3. **장소·시간**: 격자(3m × 3m)와 카메라 거리(가장자리에서 2~3m)를 합쳐 약 6m × 7m가 비는 곳이면 된다. 10/14과 같은 강의실이 아니어도 된다. 몇 시에 시작할지(2시간 30분 + 여유).
4. **카메라 거치**: 높이 2.5~3m를 어떻게 확보할지 (높은 삼각대, 벽·기둥 고정, 사다리 위 거치대). 위 "카메라 배치" 기준에 반대 의견이 있으면 같이.
5. **장면 추가·삭제**: 빠진 상황이나 줄여도 되는 장면이 있는지. 시간이 모자라면 s23부터 뺀다.
