## 4. 트랙 간 약속 (10/1 킥오프에서 확정)

### 4-1. 좌표계·형식

| 항목 | 약속 |
| --- | --- |
| 월드 좌표 원점 | 방 바닥의 한 모서리 (실측 때 테이프로 표시, 공간마다 따로) |
| 축·단위 | X = 가로, Y = 세로, Z = 위쪽 높이, 단위 m |
| Unity 변환 | Unity는 Y가 위쪽인 왼손 좌표계 → **world = (unity.x, unity.z, unity.y)**. 정답 좌표는 Unity 쪽(C)에서 변환해서 보냄 |
| 이미지 좌표 | 픽셀, 원점 = 좌상단, bbox = `[x1, y1, x2, y2]` |
| 시간 | epoch ms, 엣지가 프레임을 받은 시각 |
| 클래스 | `person`, `chair`, `cart`, `desk` (모델이 바뀌어도 이름 유지) |
| 확인 방법 | 1주차 첫날 Unity 바닥의 알려진 점 1개로 엣지 → 서버 → 월드 좌표가 맞는지 확인 |

### 4-2. 메시지 형식

| 메시지 | 보내는 쪽 → 받는 쪽 | 주요 필드 |
| --- | --- | --- |
| 탐지 결과 | 엣지 → 서버 `POST /detections` | `session_id`, `camera_id`, `frame_id`, `ts`, `image_size`, `detections[{track_id, cls, conf, bbox}]` |
| 계산 결과 (응답) | 서버 → 엣지 | `frame_id`, `objects[{track_id, cls, world:[x,y,z], speed_mps}]` |
| 캘리브레이션 | 엣지 → 서버 `PUT /cameras/{id}/calibration` | `image_size`, `K`(3×3), `dist`(k1,k2,p1,p2,k3), `rvec`, `tvec`, `reproj_error_px` |
| 정답 좌표 (시뮬만) | Unity → 서버 `POST /ground-truth` | `session_id`, `frame_id`, `ts`, `objects[{object_id, cls, world:[x,y,z], bbox}]` |

탐지 결과 예시

```json
{
  "session_id": "unity-classroom-01",
  "camera_id": "cam1",
  "frame_id": 1532,
  "ts": 1790774606123,
  "image_size": [1920, 1080],
  "detections": [
    {"track_id": 7, "cls": "person", "conf": 0.91, "bbox": [812.4, 300.2, 905.1, 610.8]}
  ]
}
```

### 4-3. API 초안

| 메서드 | 경로 | 하는 일 | 호출하는 쪽 |
| --- | --- | --- | --- |
| POST | `/sessions` | 실험 세션 생성 (env: `unity-classroom`, `unity-diy`, `real-classroom`, `real-diy`) | 엣지 |
| PUT | `/cameras/{camera_id}/calibration` | 캘리브레이션 파라미터 등록·갱신 | 엣지 |
| POST | `/detections` | 한 프레임 탐지 저장 + 월드 좌표 계산 후 반환 | 엣지 |
| POST | `/ground-truth` | Unity 정답 좌표 저장 | Unity |
| GET | `/tracks/{track_id}?session_id=` | 궤적·속도 조회 | 분석 |
| GET | `/sessions/{id}/error` | 추정 vs 정답 오차 요약 (평균·최대, 거리별) | 분석 |

### 4-4. DB 스키마 초안

| 테이블 | 주요 컬럼 | 비고 |
| --- | --- | --- |
| `session` | id, env, started_at, note | 실험 단위 |
| `camera_calibration` | id, camera_id, session_id, width, height, K(jsonb), dist(jsonb), rvec, tvec, reproj_error_px, created_at | 세션마다 다시 잴 수 있게 이력으로 저장 |
| `frame` | id, session_id, camera_id, frame_idx, ts | 인덱스 (session_id, ts) |
| `detection` | id, frame_id, track_id, cls, conf, x1, y1, x2, y2, world_x, world_y, world_z, speed_mps | 인덱스 (track_id) |
| `ground_truth` | id, session_id, frame_idx, ts, object_id, cls, world_x, world_y, world_z, x1, y1, x2, y2 | Unity 실험 + 실데이터 정답(마커·테이프 지점) 공용 |
