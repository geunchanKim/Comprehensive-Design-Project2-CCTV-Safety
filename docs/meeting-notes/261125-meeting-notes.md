## 1. 이번 주 진행 내용

### ① DIY실 실시간 연동 및 충돌 위험 경고 실험

11월 25일 DIY실에서 실제 카메라를 이용해 **시스템이 실시간으로 동작하는지 확인하고, 충돌 위험 경고를 점검하는 실험**을 진행했다.

카메라 영상 입력부터 객체 탐지·추적, 서버의 위치·위험 계산, 관제 화면 표시까지 전체 흐름을 확인했다. 사람과 물체가 가까워지는 상황에서 경고가 어떻게 발생하고 유지되는지도 점검했다.

이번 실험에서 확보한 영상과 로그를 바탕으로 추적 누락, 위치 흔들림, 경고 끊김 등의 발생 구간을 분석하고 개선할 예정이다. **오늘 실험의 정량 결과는 자료 정리 후 확정한다.**

### ② 기존 추적·경고 개선 결과 확인

기존 연동 실험에서 나타난 사람 추적 누락과 동일 상황의 경고 반복 생성 문제에 대응해 다음 기능을 반영하고 결과를 정리했다.

- **추적 연속성 보완:** 한 카메라에서만 사람이 보이는 경우에도 위치 추정을 이어가도록 처리
- **경고 연속성 보완:** 짧은 관측 끊김에서는 같은 경고 ID를 유지
- **의자 가림 대응:** 가려진 의자의 마지막 위치를 최대 3초 유지
- **화면 구분:** 실제 관측 위치와 한 카메라 추정 위치, 마지막 유지 위치를 구분해 표시

11월 22일 실행한 v95에 대해 이번 주 전달받은 결과는 다음과 같다.

| 확인 항목 | 담당자 보고 결과 |
| --- | --- |
| 탐지 데이터 전송 | 634건, 실패 0건 |
| 사람 누락 묶음 | 6건 |
| 세 명 동시 표시 비율 | 260회 조회 기준 95.8% |
| 서버 응답시간 P90 | 98.8ms |
| 입력 종료 후 활성 경고 | 3.6초 뒤 0건 |

> 위 수치는 기존 녹화 재생 실험의 결과이며, 오늘 DIY실에서 진행한 실험 결과와 구분한다.

### ③ 캘리브레이션·보호구 평가 준비

새 촬영 환경에 맞춰 카메라 캘리브레이션 방식을 보완하고, 보호구 판별과 근접 경고를 평가할 시나리오를 정리했다.

- 다점 기반 캘리브레이션으로 새 카메라 배치에 대응
- 안전모·안전조끼 착용 조합별 평가 장면 구성
- 야구모자·형광 옷 등 보호구 오인식 사례 반영
- 경고 기준 전후 거리와 가림·겹침 상황을 포함한 평가 계획 수립
- 모델 보강용 학습 데이터와 최종 평가 데이터 분리

### ④ 관제 화면 및 등록 자료 정리

관제 화면의 기능 설명, 캡처, 실행 환경을 수합하고 실제 서버에서 확인한 범위를 정리했다. 실제 검증 자료와 예시 데이터 화면을 구분했으며, 경고 확인의 서버 저장과 입력 중단 표시 등 추가 확인이 필요한 항목도 정리했다.

## 2. 실험 결과를 반영한 개선 방향

앞으로는 **DIY실에서 확인한 문제를 수정하고, 같은 조건으로 다시 실험해 개선 효과를 확인하는 데 집중한다.**

| 개선 항목 | 진행 방향 | 확인할 결과 |
| --- | --- | --- |
| 위치 추적 | 가림·겹침·화면 가장자리에서 누락되는 원인 분석 및 보완 | 사람 누락 빈도, 추적 끊김 시간 |
| 충돌 위험 경고 | 실제 거리와 계산 결과를 비교하고 경고 반복·끊김 개선 | 오탐·미탐, 경고 연속성 |
| 보호구 판별 | 실제 촬영 데이터로 모델 보강 | 착용·미착용 판별 성능, 모자·형광 옷 오인식 |
| 실시간 처리 | 탐지·전송·서버 처리 단계별 지연 분석 | 초당 처리량, 응답시간 |
| 전체 연동 | 경고 발생→화면 표시→사용자 확인→서버 저장 흐름 검증 | 화면과 서버 기록의 일치 여부 |

기존 측정에서 처리량은 **초당 7.3묶음으로 목표 10묶음에 미달**했다. 추가 측정으로 지연이 발생하는 단계를 확인하고 개선 우선순위를 정할 예정이다.
