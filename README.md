# 지능형 CCTV 기반 산업현장 안전관제 시스템

> 종합설계프로젝트2 · CCTV 영상 분석을 통한 산업현장 안전관리 지원

## 프로젝트 소개

산업현장의 CCTV 영상을 분석하여 작업자와 안전장비를 인식하고,
위험구역 침입 등 위험 상황을 탐지하는 안전관제 시스템을 개발합니다.
탐지 결과를 알림과 관제 화면으로 제공하여 관리자가 현장 상황을 파악하고 대응할 수 있도록 돕는 것을 목표로 합니다.

## 개발 목표

- **작업자 안전 상태 확인**: 작업자와 안전장비를 인식하여 현장의 안전 상태를 파악합니다.
- **위험 상황 탐지**: 작업자의 위험구역 침입을 감지합니다.
- **관제 및 대응 지원**: 위험 상황을 알리고 탐지 결과를 관제 화면에서 확인할 수 있도록 합니다.

## 주요 기능 (개발 예정)

| 기능 | 설명 |
| --- | --- |
| 영상 입력 및 처리 | CCTV 영상을 입력받아 분석에 필요한 형태로 처리 |
| 객체 탐지 | YOLO 기반으로 영상 내 작업자 및 안전장비 인식 |
| 위험구역 침입 감지 | 작업자의 위치를 바탕으로 위험구역 침입 여부 판단 |
| 위험 상황 알림 | 감지된 위험 상황을 관리자에게 전달 |
| 관제 화면 | 영상과 탐지 결과를 확인할 수 있는 화면 제공 |

## 처리 흐름 (예정)

```text
CCTV 영상 입력 → 영상 처리 → 작업자·안전장비 탐지 → 위험 상황 판단 → 알림 및 관제
```
