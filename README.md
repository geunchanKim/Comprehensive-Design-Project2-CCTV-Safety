# 지능형 CCTV 기반 산업현장 안전관제 시스템

## 프로젝트 소개

산업현장의 CCTV 영상을 분석하여 작업자의 안전 상태와
위험 상황을 탐지하기 위한 지능형 안전관제 시스템입니다.

## 주요 기능

- CCTV 영상 입력 및 처리
- YOLO 기반 객체 탐지
- 작업자 및 안전장비 인식
- 위험구역 침입 감지
- 위험 상황 알림 및 관제

## Git 사용 규칙

자세한 내용은 Git Convention 문서를 참고합니다.

- 작업 브랜치는 `feat/기능이름`, `fix/버그이름`, `docs/문서이름`처럼 영문 소문자와 하이픈으로 작성합니다.
- 커밋과 PR 제목은 `접두어: 작업 내용` 형식으로 소문자로 작성합니다. (예: `docs: 프로젝트 소개 보완`)
- `main`, `develop`에 직접 push하지 않고 PR을 통해 반영합니다.
- PR을 올리기 전에 diff를 확인하고, 최소 한 명의 리뷰를 받은 뒤 병합합니다. 셀프 머지는 금지합니다.
